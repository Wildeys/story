# ތެމިފޯވެފައި، ނަމަވެސް ހިނިތުންވަމުން

A short Dhivehi story presented as a swipeable, story-style web page.

## Files

```
index.html
images/rainy-steps.jpg
fonts/faruma.ttf      ← add this yourself (see below)
```

## Faruma font

Faruma can't be bundled here, so copy your own `faruma.ttf` into the `fonts/` folder
(the name must be lowercase: `fonts/faruma.ttf`). Until you do, readers who have Faruma
installed will still see it, and everyone else gets Noto Sans Thaana as a fallback.

## Publish on GitHub Pages

1. Create a new repository and upload all the files, keeping the folders.
2. Go to **Settings → Pages**, set Source to **Deploy from a branch**, pick `main` and `/ (root)`, and save.
3. After a minute the story is live at `https://<your-username>.github.io/<repo-name>/`.

Link to a specific page by adding `#3`, `#6`, etc. to the URL.
